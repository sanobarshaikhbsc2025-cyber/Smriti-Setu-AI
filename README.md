## 🚀 Overview

**Smriti-Setu AI** is an offline-first health bridge designed specifically for Bharat’s elderly population. By leveraging on-device AI models, it enables instant medical screenings without requiring active internet connectivity.

---

## ✨ Key Features

- 📱 **Offline-First Medical Screening:** Runs lightweight **TensorFlow Lite** models directly on-device without internet dependencies.
- 🎙️ **Vernacular Voice Assistant:** Supports 22+ local Indian languages to break technology barriers for senior citizens.
- 📊 **Care-Connect Dashboard:** Enables distant children/caregivers to monitor their parents' wellness index in real-time.
- ⚡ **Low Latency & High Privacy:** Local execution ensures zero data leakage and instant diagnostic feedback.
